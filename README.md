🚀 Билим Арена — Кванттык Билим Платформасы
Билим Арена — бул мектеп окуучулары үчүн иштелип чыккан, 100% кыргыз тилиндеги билим берүүчү жана оюн платформасы. Долбоор логиканы, реакцияны жана стратегиялык ой жүгүртүүнү өстүрүүгө багытталган заманбап оюндарды камтыйт.

✨ Өзгөчөлүктөрү
Интерактивдүү Зона (AI & Computer Vision): Веб-камера аркылуу колдун кыймылы (gestures) менен башкарылуучу инновациялык оюндар.

Түнкү жана Күндүзгү режим: Колдонуучунун каалоосуна жараша интерфейстин түсүн өзгөртүү мүмкүнчүлүгү (Dark/Light mode).

Ыкчам издөө жана фильтрация: Оюндарды категориялар (Логика, Реакция, Текст ж.б.) боюнча оңой табуу.

Сүйүктүү оюндар: Каалаган оюнду "Тандалмалар" тизмесине кошуу функциясы.

Заманбап Дизайн: Glassmorphism стилиндеги интерфейс жана жылмакай анимациялар.

🏅 Прогресс системасы (жаңы)
XP жана деңгээлдер, күнүмдүк серия 🔥, күнүнө 100 XP максаты, 8 белги, «Күндүн сөзү». Бардыгы браузерде (localStorage) сакталат — каттоо керек эмес.

📚 Тил үйрөнүү оюндары (жаңы)
Бардыгы бир жалпы сөздүктү колдонот: 129 сөз, 10 тема, 3 тил (кыргызча / орусча / англисче).

Сөз карточкалары: Карточканы бурап, котормосун көр жана ук. Лейтнер системасы унутула баштаган сөздөрдү кайра чыгарат.
Жупташтыр: Эс тутум оюну — сөз менен анын котормосун (же сүрөтүн) жупташтыр.
Сөз табышмак: Кыргызча Wordle — 5 тамгалуу сөздү 6 аракетте тап. Күн сайын жаңы сөз.
Сөз жамгыры: Аркада — сөз жерге түшкөнчө туура котормону бас. Комбо жана деңгээлдер.
Шарлар: Сүрөт жана котормо боюнча кыргыз сөзүн тамга-тамга тап (Ң, Ө, Ү менен).

🕵️ Мафия — онлайн (жаңы)
Класс менен телефон аркылуу ойнолуучу «Мафия». Мугалим бөлмө түзөт, окуучулар QR-код же 4 белгилүү код менен кошулат.

Сервер да, каттоо да керек эмес: браузерлер өз ара түз туташат (WebRTC / PeerJS).

Ролдор жеке жөнөтүлөт — башка оюнчунун ролун көрүү мүмкүн эмес.

Байланыш үзүлсө (телефон өчүп калса) оюнчу автоматтык түрдө кайра кошулат.

Алып баруучунун панели: ар бир фаза үчүн даяр текст жана авто-үн.

Кеминде 4 оюнчу керек, жетишпесе роботтор кошулат.

⚠️ Маанилүү: оюн алып баруучунун браузеринде иштейт — ал бетти жаппашы керек.

🎮 Оюндардын тизмеси
Классикалык оюндар:
Сүйлөмдү түз: Сөздөрдөн туура сүйлөм курап, тил байлыгыңызды сынаңыз.

Ашыкчаны тап: Логикалык катардагы туура келбеген элементти табыңыз.

Фокус Дуэль: Реакцияңызды текшерип, элементтерди тезирээк табыңыз.

Цитаделди ээлөө: Суроолорго жооп берип, стратегиялык аймактарды басып алыңыз.

Интерактивдүү (Webcam) оюндар:
Кыргыз Бүркүтү: Колдун кыймылы менен бүркүттү башкаруу (Flappy Bird стилинде).

Ылдамдык сыноо: Виртуалдык объекттерди камера аркылуу кармоо.

Неон Сүрөт: Абада кол менен сүрөт тартуу (AI жардамы менен).

🛠 Технологиялык стек
HTML5 & CSS3: Заманбап структура жана анимациялар үчүн (Custom Properties, Flexbox, Grid).

JavaScript (Vanilla): Платформанын логикасы жана фильтрация үчүн.

MediaPipe / AI: Веб-камера аркылуу жесттерди таануу үчүн колдонулат.

Local Storage: Колдонуучунун тандаган темасын жана сүйүктүү оюндарын сактоо үчүн.

🚀 Кантип иштетүү керек?
Репозиторийди көчүрүп алыңыз:

Bash
git clone https://github.com/akbaralievernis/bilim_arena.git
Долбоордун папкасына кириңиз:

Bash
cd bilim_arena
index.html файлын каалаган браузерде ачыңыз.

📁 Структура
index.html — Негизги бет.

portal.css — Негизги стилдер жана дизайн.

portal.js — Логика, оюндардын тизмеси жана функциялар.

/assets — Сүрөттөр жана графикалык элементтер.

/games — Ар бир оюндун өзүнчө булак коддору.

/mafia-src — «Мафия» оюнунун булак коду (React + Vite). Өзгөртүү киргизгенден кийин:
cd mafia-src && npm install && npm run build — даяр файлдар /games/mafia папкасына түшөт.

/shared/vocab.js — жалпы сөздүк. Жаңы сөз кошуу: тиешелүү категорияга ['эмодзи', 'кыргызча', 'орусча', 'english'] сабын кошуңуз — бардык тил оюндарында дароо пайда болот.

/shared/progress.js — XP, деңгээл, серия, белгилер, үн эффекттери жана үн менен окуу (Text-to-Speech).

/shared/game.css, /shared/game-shell.js — тил оюндарынын жалпы дизайны, тема жана тил тандоо.

sw.js, manifest.webmanifest — офлайн режим жана телефонго «колдонмо» катары орнотуу (сайт http/https аркылуу ачылганда иштейт). Файлдарды өзгөрткөндөн кийин sw.js ичиндеги VERSION'ду көбөйтүңүз.

💡 Эскертүү: Офлайн режим жана веб-камера оюндары үчүн сайтты сервер аркылуу ачыңыз (мисалы, GitHub Pages же `python -m http.server`).
