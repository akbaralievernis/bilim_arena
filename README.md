# 🚀 Билим Арена

Мектеп үчүн интерактивдүү окуу платформасы: **доска — негизги экран, окуучулардын телефондору — пульт.**
Үч тил: кыргызча (негизги), орусча, англисче — аралашпайт. Каттоосуз иштейт; Supabase туташтырылса — аккаунттар жана жалпы маалымат.

Сайт: https://akbaralievernis.github.io/bilim_arena/

---

## Кыргызча

### Кантип колдонулат
- **Мугалим / доска** — `board.html`: предмет, тема, режим тандалат → QR-код же 4 белгилүү код чыгат → окуучулар телефон менен кошулат → оюн → каталар боюнча талдоо.
- **Окуучу** — `index.html` (башкы бет), `games.html` (бардык оюндар: издөө, чыпкалар, бөлүмдөр), `play.html` (сабакка кирүү), `practice.html` (машыгуу), `speak.html` (айтылыш), `tasks.html` (үй тапшырмалар), `progress.html` (профиль: деңгээл, XP, жетишкендиктер, каталар).
- **Мугалим** — `teacher.html` (панель), `homework.html` (үй тапшырма түзүү жана аналитика), `questions.html` (суроолор китепканасы жана конструктор, 10 түр).

### Мазмун
16 предметтин баары боюнча темалар: 17 тема, 218 тапшырма. Ар бир тапшырма тема → көндүм → суроо түзүмүндө, ошондуктан каталар көндүм деңгээлинде талданат.

### Булут (Supabase)
Туташтырылса: мугалим почта менен кирет жана класс түзөт (ар бир класстын 6 белгилүү коду бар), окуучу ☁️ Аккаунт бетинде коду жана аты менен кирет — почта керек эмес. Тапшырмалар жана натыйжалар булут аркылуу жүрөт. Туташтыруу тартиби — төмөндө, «Supabase» бөлүмүндө.

## Русский

### Как пользоваться
- **Учитель / доска** — `board.html`: выбрать предмет, тему и режим → QR-код или 4-значный код → ученики подключаются с телефонов → игра → разбор ошибок по навыкам.
- **Ученик** — `index.html` (главная), `games.html` (каталог: разделы «Языки», «Логика», «Командные», «С камерой», поиск, фильтры по предмету, типу, сложности, игрокам и устройству, сортировка), `play.html` (вход на урок), `practice.html` (практика), `speak.html` (произношение), `tasks.html` (домашние задания), `progress.html` (профиль: уровень, XP, дневная цель, серия, достижения, ошибки с объяснениями).
- **Учитель** — `teacher.html` (панель), `homework.html` (задания и аналитика класса, «Повторить тему» по реальным ошибкам), `questions.html` (библиотека и конструктор вопросов, 10 типов).

### Игры
Для доски — 9 игр из таблицы выше: быстрый опрос, захват территории, расследование, ошибка учителя, карта истории, кодовый замок, формула-бой, лаборатория, экономика города. Самостоятельно — «Говори!» (распознавание речи в браузере; где его нет — режим «Послушай и напиши»), старые языковые игры и «Мафия».

### Архитектура
```
core/            движок и общие модули
  engine.js      BaseGame: start / pause / resume / nextQuestion / scoreAnswer / finish / buildResults / saveResult
  curriculum.js  предметы, темы, навыки, getQuestions()
  progress.js    XP (только за учебные действия), навыки, ошибки, значки
  realtime.js    комнаты доска ↔ телефоны (WebRTC через PeerJS)
  quiz-ui.js     отрисовка всех типов заданий
  speech.js      распознавание и синтез речи
  ui.css         дизайн-система: светлая палитра, кнопки, карточки, поля, навигация
  icons.js       набор SVG-иконок в одном стиле (вместо эмодзи)
  art.js         иллюстрации: обложки игр и категорий, иллюстрация профиля
  catalog.js     карточки игр и категорий, поиск и сортировка (главная и каталог)
  store.js       хранилище: всё пишется локально, изменения уходят в облако через onWrite
  cloud.js       Supabase: вход учителя и ученика, классы, синхронизация
  config.js      адрес проекта Supabase и anon-ключ (пусто — локальный режим)
  sync.js        передача домашних заданий через урок, без сервера
games/<id>/      игры — только логика и отрисовка, без вопросов внутри
data/games.js    каталог всех игр: раздел, предметы, тип, сложность, игроки, устройства, время
data/questions/  банки вопросов по темам
data/investigations/, data/labs/, data/speaking/  дела, опыты, наборы для произношения
locales/         ky / ru / en
```

### Как добавить контент
- **Игра в каталоге:** запись в `data/games.js` (раздел, предметы, тип, сложность, игроки, устройства, иконка и тон иллюстрации).
- **Тема:** файл в `data/questions/` + запись в `TOPICS` (`core/curriculum.js`) с навыками.
- **Вопрос:** `{ id, skill, difficulty, type, prompt:{ky,ru,en}, …, explain:{ky,ru,en} }`. Типы: `choice`, `multiple`, `input` (`numeric`), `match`, `sort`, флаг `errorHunt` для «Ошибки учителя». Учитель может добавлять вопросы прямо в конструкторе.
- **Расследование / опыт / набор слов:** файлы в `data/investigations`, `data/labs`, `data/speaking`.
- Новые файлы добавить в список кеша `sw.js` и увеличить `VERSION`; при изменении страниц — поднять `?v=` у подключаемых файлов.

### Безопасность и данные
- Нет секретных ключей во frontend и в репозитории.
- Персональные данные минимальны: имя, роль, номер класса и аватар. Без облака всё хранится на устройстве (localStorage); с Supabase — ещё и в облаке, где правила RLS дают учителю доступ только к результатам, прогрессу и ошибкам своих учеников.
- Микрофон используется только на `speak.html` и только по нажатию; распознаёт сервис браузера, запись не сохраняется.

### Supabase: аккаунты и общие данные
Без настройки платформа работает локально, как раньше. После подключения:
- **учитель** входит по почте и паролю, создаёт классы — у каждого свой 6-значный код;
- **ученик** на странице ☁️ Аккаунт вводит код класса и имя — почта не нужна (анонимный вход Supabase);
- задания уходят ученикам класса, результаты — учителю; прогресс ученика и данные учителя хранятся в облаке, учитель видит всё с любого устройства;
- всё по-прежнему пишется сначала локально и работает без интернета, синхронизация — в фоне.

**Как подключить (один раз, ~10 минут):**
1. [supabase.com](https://supabase.com) → New project (регион поближе, например Frankfurt).
2. **SQL Editor** → вставить весь файл `supabase/schema.sql` → **Run**.
3. **Authentication → Sign In / Providers**: включить **Allow anonymous sign-ins** (вход учеников); Email оставить включённым.
4. **Authentication → URL Configuration**: Site URL — `https://akbaralievernis.github.io/bilim_arena/`, в Redirect URLs добавить `https://akbaralievernis.github.io/bilim_arena/account.html`.
5. **Authentication → Rate Limits**: поднять лимит анонимных входов (по умолчанию 30 в час с одного IP) — в школе весь класс выходит в интернет с одного адреса.
6. Встроенная почта Supabase отправляет лишь несколько писем в час: для многих учителей подключите свой SMTP (Authentication → Emails) или отключите подтверждение почты.
7. **Project Settings → API**: скопировать **Project URL** и ключ **anon public** в `core/config.js`.

⚠️ В `core/config.js` — только `anon`-ключ. Ключ `service_role` в код не вставлять никогда.

**Проверка схемы и синхронизации:** `cd supabase/tests && npm install && npm test` — схема и `core/cloud.js` прогоняются на настоящем Postgres (PGlite): 37 проверок правил доступа и 23 сквозных сценария учитель ↔ ученик.

### Ограничения и что дальше
- **Без Supabase** данные хранятся на каждом устройстве отдельно; домашние задания передаются через урок на доске (`core/sync.js`).
- **Ученик привязан к устройству**: анонимный аккаунт нельзя открыть на другом телефоне. Если ученик сменит устройство — он снова входит по коду класса (учитель может удалить старую запись в списке класса).
- **AI** (генерация заданий, объяснения) — только через сервер (например, Supabase Edge Function), чтобы ключ API не попал в браузер.
- Комнаты работают через публичный сервер сигналинга PeerJS; при его недоступности урок на телефонах не подключится (самостоятельные режимы работают).

### Локальный запуск
```bash
python -m http.server 8765
```
Открыть http://localhost:8765. Сборка не нужна (кроме `mafia-src` — React/Vite, собирается в `games/mafia`).
